# Package index

## Formatting

Functions made for formatting output for Quarto or Rmarkdown. Also
useful for copy-pasting outputs from the R console.

- [`format_num()`](http://package.aleksanderbl.dk/reference/format_num.md)
  : Format a number for presentation

## Themes

Theme functions for differnet types of plots

- [`theme_map()`](http://package.aleksanderbl.dk/reference/theme_map.md)
  :

  A theme made for maps from
  [`ggplot2::geom_map()`](https://ggplot2.tidyverse.org/reference/geom_map.html).

- [`theme_map_color()`](http://package.aleksanderbl.dk/reference/theme_map_color.md)
  :

  A color-ready theme made for maps from
  [`ggplot2::geom_map()`](https://ggplot2.tidyverse.org/reference/geom_map.html).

## Misc.

Other useful functions

- [`pkg_bib()`](http://package.aleksanderbl.dk/reference/pkg_bib.md) :

  Create bibliography of
  [renv](https://rstudio.github.io/renv/)-installed packages

- [`plot_nchar()`](http://package.aleksanderbl.dk/reference/plot_nchar.md)
  :

  Get character count from `ggplot2` object.

- [`parties`](http://package.aleksanderbl.dk/reference/parties.md) :
  List of parties up for election
