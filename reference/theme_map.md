# A theme made for maps from `ggplot2::geom_map()`.

This theme is made specifically for maps made with. A color-ready
version exists as
[`theme_map_color()`](http://package.aleksanderbl.dk/reference/theme_map_color.md).

## Usage

``` r
theme_map(base_size = 9, base_family = "")
```

## Arguments

- base_size:

  base font size, given in pts.

- base_family:

  base font family
